# Bem vindo ao Backend-creator
## Descrição
Fazer um **criador de backend** com banco de dados no computador com a ajuda de IA
## Tecnologias utlizadas
- Gemini
- Node.js
- SQL
- HTML
## Tutorial
- Abra o site:
https://eduardomorettiv.github.io/backend_creator/
1. Cole um script.sql
2. Clique em *Baixar como zip*
3. No local que você colocou a pasta, clique em *extrair tudo*
4. Abra com o code
5. **Crie a pasta `.gitignore` com `node_modules` e `package-lock.json`!**
6. Rode no terminal `npm install express cors mysql2`
7. Rode `node server.js`
